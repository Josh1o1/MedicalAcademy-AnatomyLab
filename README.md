# 🧬 Medical Academy — 3D Anatomy Lab

An interactive 3D anatomy learning experience built for **Medical Academy**.

The Anatomy Lab uses **Three.js** and WebGL to provide an interactive anatomical environment where learners can rotate, zoom, inspect, and identify anatomical structures.

## ✨ Features

- 🦴 Interactive 3D skeleton
- 🔄 Rotate and inspect the model
- 🔍 Zoom and explore structures
- 👆 Interactive structure selection
- 🎯 Anatomical identification challenge
- 📱 Mobile-friendly interface
- 🌐 Runs directly in the browser
- 📲 Designed to integrate with the Medical Academy Telegram Mini App

## 🏗️ Technology

- HTML5
- CSS3
- JavaScript
- Three.js
- WebGL
- Telegram Web Apps API

## 🩺 Medical Academy Integration

The Anatomy Lab is a visual learning component of the larger Medical Academy platform.

The planned architecture is:

Medical Academy Telegram Bot  
↓  
Body Explorer  
↓  
3D Anatomy Lab  
↓  
Interactive anatomical learning

Future versions will connect anatomical structures with lessons, quizzes, progress tracking, and clinical learning content.

## 🚀 Development

The project is currently in its prototype phase.

Current focus:

- Interactive skeletal anatomy
- Anatomical structure identification
- Mobile-first 3D interaction

Future development will introduce more detailed anatomical models and additional body systems.

## 📚 Educational Purpose

This project is designed for educational purposes and is not intended to provide medical diagnosis or replace professional medical advice.
